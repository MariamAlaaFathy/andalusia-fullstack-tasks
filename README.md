# Full Stack Development (.NET + React) — ITIDA Training to Hire

This repository contains my tasks and exercises completed as part of the **Full Stack Development (.NET + React)** training program under the **ITIDA Training to Hire** initiative, delivered by **Andalusia Academy**.

## Repository Structure

Each task is organized into its own folder in the `main` branch, so all tasks can be browsed in one place.

In addition, **each task also has its own dedicated branch**, containing that task's work in isolation. This makes it easier to review, run, or track a specific task without navigating through the rest of the repository.

## About the Program

This training is part of ITIDA's **Training to Hire** program, aimed at preparing candidates for industry roles through hands-on, project-based learning in full stack web development using **.NET** (backend) and **React** (frontend).

## Notes

- Each folder/branch may include its own instructions, source code, and any relevant notes specific to that task.
- This repository is a personal record of coursework and is updated as new tasks are completed.
